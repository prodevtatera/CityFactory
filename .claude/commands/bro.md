description: Restate the last answer in plain, jargon-free language
---

Restate your last answer in plain language. Narrow it to $ARGUMENTS if supplied.
This does not redo the work, change the conclusion, or check anything again.

1. Use the same language as the answer being restated.
2. Replace jargon with ordinary words. If a technical term is essential, define it once.
3. Lead with what the answer means for the user, then only the reasoning that matters.
4. Keep every number, name, file path and URL exactly as it was. Preserve uncertainty,
   unfinished work and anything that was not checked.
5. Make it shorter than the original.
6. Add no new facts, caveats, suggestions or offers. If the answer asked a question,
   ask that same question plainly.

If the answer was already plain, say so in one line instead of padding it out.
